# 📚 Recursos, Materiais e Referências de Estudo

Este guia reúne todos os materiais de apoio, links de documentações oficiais, cursos da plataforma DIO e referências bibliográficas recomendadas para o seu **Plano de Estudos de 30 Dias para Back-End**.

---

## 🌟 Referências Centrais e Prioritárias

Esses são os pilares que acompanharão todas as 4 semanas:

1. **Plataforma DIO (Bootcamps & Trilhas)**:
   - **Bootcamp CI&T - Java AI Copilot**: Aproveite os módulos de desenvolvimento Java moderno, integração com IA e boas práticas.
   - **Trilhas de Ecossistema Java & Spring Framework**: Para aprofundar em injeção de dependência, REST controllers e persistência.
   - **Trilha de Git e GitHub**: Para apoio direto nas aulas práticas da Semana 1.
2. **Repositório Pessoal no GitHub**:
   - Manter a prática diária de commits atômicos e descritivos.
   - Publicar desafios, anotações de código e projetos finais para montar seu portfólio.
3. **Documentações Oficiais**:
   - [Oracle Java Documentation](https://docs.oracle.com/en/java/)
   - [Spring.io Official Guides & Reference](https://spring.io/guides)
   - [Python Official Documentation](https://docs.python.org/3/) (caso opte por suporte em Python/FastAPI)
   - [Git Documentation (Pro Git Book em Português)](https://git-scm.com/book/pt-br/v2)

## 🛠️ Ferramentas Recomendadas para Instalar

Para garantir agilidade sem perder tempo durante as sessões de 1 hora diária:

- **IDEs**: [Visual Studio Code](https://code.visualstudio.com/) ou [IntelliJ IDEA Community Edition](https://www.jetbrains.com/idea/download/).
- **Gerenciador de Banco de Dados**: [DBeaver Community](https://dbeaver.io/) (gratuito e universal para SQLite, PostgreSQL, MySQL) ou extensão do VS Code (*Database Client*).
- **Testes de API**: [Postman](https://www.postman.com/), [Insomnia](https://insomnia.rest/) ou [Bruno](https://www.usebruno.com/).
- **Extensões VS Code Recomendadas**:
  - *GitLens* (análise de histórico e commits)
  - *Extension Pack for Java* (se estudar na trilha Java)
  - *Python Extension* (se estudar na trilha Python)
  - *REST Client* (para testar chamadas HTTP em arquivos `.http` direto no editor)
